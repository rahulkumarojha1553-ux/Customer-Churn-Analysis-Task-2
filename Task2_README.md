# Task 2 – Exploratory Data Analysis & Business Intelligence

## Customer Churn Analysis

This repository contains the deliverables for Task 2 of the ApexPlanet 60-Day Data Analytics Internship.

### Objective
Explore customer churn using descriptive statistics, univariate/bivariate analysis, multivariate analysis, correlation and SQL business questions, then plan an interactive dashboard.

### Tools
Python, Pandas, NumPy, Matplotlib, Seaborn, SQLite/SQL and Jupyter Notebook.

### Deliverables
- `Task2_EDA.ipynb`
- `Task2_SQL_Queries.sql`
- `Task2_EDA_Report.docx`

### Analysis
- Descriptive statistics
- 20+ visual analyses
- Churn-rate analysis
- Correlation analysis
- 20 SQL business questions
- Dashboard planning

Dataset: IBM Telco Customer Churn dataset prepared during Task 1.
